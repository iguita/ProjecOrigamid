## 🚀 Projetos

### 🐾 Animais Fantásticos

**Stack:** HTML, CSS e JavaScript

Projeto interativo que pratica manipulação do DOM e eventos em JavaScript. O usuário interage com elementos da página que exibem informações sobre animais fantásticos.

**Conceitos aplicados:**
- Manipulação do DOM
- Eventos de clique e interação
- Estilização com CSS
- Estruturação semântica com HTML

---

### 🚲 Bikcraft

**Stack:** HTML e CSS

Site institucional para uma marca fictícia de bicicletas artesanais. Foca na apresentação visual do produto com um layout polido e responsivo.

**Conceitos aplicados:**
- Layout de site institucional
- Estilização visual avançada com CSS
- Seções: hero, produtos, serviços e contato
- Responsividade com media queries

---

### 📰 FlexBlog

**Stack:** HTML e CSS

Projeto focado no estudo e prática do modelo de layout Flexbox. Simula um blog com múltiplas seções dispostas de forma flexível e responsiva.

**Conceitos aplicados:**
- CSS Flexbox: `flex-direction`, `justify-content`, `align-items`
- Layouts responsivos sem frameworks
- Organização de componentes em linhas e colunas
- HTML semântico

---

### 🐺 Wildbeast

**Stack:** HTML e CSS

Projeto dedicado ao aprendizado de CSS Grid Layout. Apresenta um site sobre animais selvagens com um grid complexo de múltiplas colunas e linhas.

**Conceitos aplicados:**
- CSS Grid: `grid-template-columns`, `grid-template-rows`, `grid-area`
- Layouts de grade complexos
- Combinação de Grid e Flexbox
- Design responsivo com grid adaptativo

## ▶️ Como Usar

Por se tratarem de projetos estáticos, não há dependências ou build necessário.

```bash
# Clone o repositório
git clone https://github.com/IgorBernardino/ProjectOrigamid.git

# Acesse a pasta do projeto desejado
cd ProjectOrigamid/bikcraft

# Abra o index.html no navegador
# Ou use a extensão Live Server no VS Code
```
